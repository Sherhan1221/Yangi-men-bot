# YANGI MEN — Telegram-бот (@Anush0009_bot)

Структура строго по ТЗ:
1. Landing → кнопка «YANGI MEN'GA QO'SHILISH»
2. Блок 1 — оплата (карта, сумма, кнопка «TO'LOV QILDIM»)
3. Блок 2 — Ism/Familiya + Telefon + Chek
4. Данные уходят администратору
5. Админ вручную проверяет и сам добавляет в закрытую группу
6. Бот НЕ отправляет ссылку на группу автоматически

## Деплой на Railway (бесплатно, работает 24/7 весь месяц рекламы)

### Вариант А — через GitHub (проще)
1. Создай приватный репозиторий на GitHub, залей туда все 5 файлов из этой папки
2. Зайди на railway.app → New Project → Deploy from GitHub repo → выбери репозиторий
3. Railway сама определит Python-проект и начнёт билд

### Вариант Б — без GitHub, через CLI
```
npm i -g @railway/cli
railway login
cd папка_с_ботом
railway init
railway up
```

### Настройка после деплоя (для обоих вариантов)
1. В проекте на Railway → вкладка **Variables** → добавь:
   - `BOT_TOKEN` (получить у @BotFather)
   - `ADMIN_CHAT_ID` (узнать у @userinfobot)
   - `CARD_NUMBER`
   - `CARD_HOLDER`
   - `COURSE_PRICE`
2. Вкладка **Settings → Networking → Generate Domain** — получишь адрес вида `https://xxxx.up.railway.app`
3. Добавь ещё одну переменную: `WEBHOOK_URL` = этот адрес (без слэша в конце)
4. Railway автоматически передеплоит бота — при старте он сам зарегистрирует webhook у Telegram
5. Напиши боту `/start` в Telegram — должно появиться приветствие с кнопкой

`PORT` вручную указывать не нужно — Railway подставляет её сама.

## Бесплатный лимит
$5 кредита в месяц на Railway. Для одного бота с обычной нагрузкой (не десятки тысяч сообщений в день) этого хватает с запасом на все 30 дней рекламной кампании. Карта не списывается, кредит просто списывается с бесплатного лимита.
